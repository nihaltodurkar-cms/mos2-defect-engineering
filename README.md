# mos2-defect-engineering
First-principles (DFT) investigation of defect engineering in monolayer MoS2 using Quantum ESPRESSO, including vacancies, electronic structure, DOS, PDOS, band structure and charge density analysis.
## Objective

This repository contains Density Functional Theory (DFT) calculations on monolayer MoS₂ to investigate the effect of intrinsic defects on its electronic properties.

## Software

- Quantum ESPRESSO
- VESTA
- Python
- matplotlib

## Systems

- Pristine monolayer MoS₂
- Single sulfur vacancy
- Future doped structures

## Properties

- Geometry optimization
- SCF
- NSCF
- Density of States (DOS)
- Projected DOS (PDOS)
- Band structure
- Charge density
